# KJA Website — Template Drafts

Three draft page templates (Home, Admissions, About) for the Kampala Junior
Academy website brief, built for an internal review meeting.

- `index.html` — self-contained, open directly in a browser (no build step).
- Use the **Home / Admissions / About** tabs to switch templates and the
  **Desktop / Mobile** toggle to preview the responsive layout.
- Hatched blocks are image placeholders (sized for their slot); all copy,
  names, and fee figures are illustrative sample content, not final.

This is a standalone draft for review purposes and is not wired into the
Elyon Nest app in this repository.
